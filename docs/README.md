# OctoAcme Project Management Docs

Welcome to the OctoAcme project management documentation. This folder contains process guides that cover the full project lifecycle — from initiation to retrospective — and define the roles, artifacts, and workflows used across all cross-functional projects.

## Process Summary

OctoAcme follows an iterative, customer-first delivery approach guided by five lifecycle phases:

1. **Initiation** — Validate the business need, align stakeholders, define success metrics, and decide go/no-go for planning.
2. **Planning** — Break work into shippable increments, estimate scope, identify dependencies and risks, and create a release plan.
3. **Execution & Tracking** — Build and test in sprints, maintain a project board, run standups and delivery syncs, and escalate blockers promptly.
4. **Release & Deployment** — Standardize releases with pre-release checks, deployment checklists, rollback plans, and stakeholder announcements.
5. **Retrospective & Continuous Improvement** — Capture learnings after each sprint or milestone and convert them into tracked action items.

Key roles include the **Project Manager** (delivery coordination), **Product Manager** (outcomes and backlog), **Developers** (implementation), and **QA/Testing** (quality). All projects maintain core artifacts: a Project Charter/One-pager, Risk Register, Backlog, and Retrospective notes.
